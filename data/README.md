# Local data

Keep source exports, frames, videos, generated media, labels and manifests containing sensitive information outside Git. The historical scripts expect permitted exports under `data/indoor` and `data/outdoor` and generate folds under `data/sr`. Do not redistribute student footage. Review licenses and permissions before use. Describe non-sensitive metadata using the [registry example](../configs/datasets/registry.example.yaml) and follow the [data protocol](../docs/DATA_PROTOCOL.md).
